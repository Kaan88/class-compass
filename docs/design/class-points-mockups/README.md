# Class Stars mockups

Static HTML mockups for `docs/design/class-points-brief.md` (section 10): the five board concepts, Star tiles with Options A/B/C, and the supporting teacher and student screens, in Turkish (default) and English.

**Open:** double-click `index.html`. No build, no network. `mockups.css` holds the app's `--cc-*` token values (default theme "classroom", plus "explorer" and "animals" behind the Theme buttons); `mockups.js` draws the frames and runs the demo.

**Choices the brief left open:** the class has 19 children, first names only (the brief's twelve plus seven); on the S strip a long Turkish line shows as many items as fit, never a cut word (so two names plus "+N", not three); Star tiles' 4a/4c/4b are shown in Option order A, B, C; the album wall's L box scrolls a little at 19 children; the "Needs work" chips on the phone (Option B) are neutral, not warning-coloured; at 1280 × 720 the mountain flattens and shows 10 per camp plus "+N"; the jar's S strip drops the reward when it does not fit.

**Not real:** static fictional data; the board's routine, timer, counter, grid and dock are simplified drawings; the mascot, avatars and stickers are simple original shapes, not the app's art; there is no sound; class-facing text follows the page's language switch here, while the app would use the class's language; the live demo is shared by all five boards and forgets everything on reload; static frames are marked `inert` (pictures, described by their captions).
