# Quick start for administrators

Set up a school in Class Compass. The full [Administrator guide](admin.md) explains each page.

1. **Your account.** The IT person creates the first administrator account on the server. Administrators always sign in with a password.
2. **School settings.** **School name**, **School timezone**, **Week starts on** and **Language for new accounts**.
3. **School year.** **School years and terms** → **New school year**, then **Add term**.
4. **Subjects and classes.** **Subjects** → **New subject**; **Classes** → **New class** (name, grade, class language).
5. **Teachers.** **Accounts** → **New account** with an **Invite link (recommended)**. Then **Teaching assignments** → **Assign a teacher** to each class and subject: a teacher sees a class only through an assignment.
6. **Modules and media.** Decide which modules the school uses. Keep **Student photos**, **Photo evidence** and **Audio evidence** off until consent is confirmed (KVKK).
7. **Students.** **Import students** → choose a class → read its e-Okul list → confirm. Empty classes are marked, so you can fill every class before teachers start. Teachers can also import their own lists, and you can **Add student** on **Students**.

Then check **Maintenance** regularly: backup status and warnings. Restoring a backup is done on the server (see `docs/OPERATIONS.md`).

Optional:

- **Super Speakers**, the school-wide English points board ([Super Speakers guide](super-speakers.md)).
- **Themes**: import a theme package, preview it and enable it for teachers ([Themes](admin.md#themes)).
- **AI tools**: let teachers connect an AI assistant; student names stay inside the school by default ([AI tools guide](ai-tools.md)).
